Как перевести пользователя на RADIUS

Через админку или через API: 

manage.py shell -c "
from django.contrib.auth import get_user_model
from apps.access.models import UserAuthSettings
User = get_user_model()
u = User.objects.get(username='alice')
s, _ = UserAuthSettings.objects.get_or_create(user=u)
s.auth_source = 'radius'
s.save()
"

После смены источника пользователь сможет зайти только через RADIUS с паролем+OTP. Локальный пароль Django перестаёт работать.
